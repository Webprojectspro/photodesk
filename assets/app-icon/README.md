# App icon

`photocraft.svg` (machine filename kept from upstream) is the canonical PhotoDesk icon:
a white lens ring with viewfinder corner brackets on a navy (#1F3B57) rounded tile.
`photocraft-small.svg` is the simplified trace used for the scalable hicolor icon.

Regenerate every size with `packaging/icons.sh` (needs `resvg`; on macOS `iconutil`
also rewrites the `.icns`). The outputs are committed.
